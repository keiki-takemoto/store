プライバシーポリシー

ZIPANGレジ

ZIPANGレジは、お客さまの個人情報を集めません。 アカウント登録も要りません。アプリに入れた内容は、お店の端末と、 お店ご自身が用意した保管場所にだけ保存されます。 開発者がそれを見ることはできません。

1. 集めない情報

このアプリは、次のものを一切集めません。

  • お名前・メールアドレス・電話番号・住所
  • 位置情報
  • カメラ・マイク・写真・連絡先・カレンダー
  • 端末の識別子、広告のための情報
  • アプリの使われ方を記録するもの（アクセス解析）

広告は表示しません。第三者に情報を渡すこともありません。

2. アプリに入れた内容の置き場所

商品・売上・スタッフ・シフトなど、お店が入れた内容は、 まずその端末の中だけに保存されます。

複数の端末で同じ内容を見たい場合にかぎり、 お店ご自身が用意したデータベース（Supabase）につなぐことができます。 つなぎ先はお店が自分で入力するもので、 開発者が用意したサーバーではありません。 つながない場合、内容が端末の外に出ることはありません。

どちらの場合も、開発者がお店の内容を見ることはできません。

3. Bluetoothの使い道

Bluetoothは、レシートプリンタに紙を出すためだけに使います。 位置の推定には使いません。ほかの機器に接続することもありません。

4. 画面の配信について

アプリの画面は GitHub Pages（GitHub, Inc.）から配信しています。 そのため、アプリを開いたときに、通信の記録（IPアドレスなど）が 同社のサーバーに残ることがあります。これは一般的なウェブサイトの閲覧と同じもので、 開発者がその記録を使って個人を特定することはありません。

5. お子さまについて

このアプリはお店の業務用です。お子さまに向けたものではなく、 年齢にかかわらず個人情報を集めません。

6. 内容の削除

端末に入っている内容は、アプリの 「設定 → 置き場所 → データ → 全部消す」で消せます。 お店が用意したデータベースの内容は、お店ご自身で削除できます。 開発者が預かっているものはないため、削除のご依頼は不要です。

7. 変更

このポリシーを変更するときは、このページを更新します。 大きな変更があるときは、アプリの更新内容でもお知らせします。
