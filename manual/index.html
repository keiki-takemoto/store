このアプリの使い方です。わからなくなったら、ここを開いてください。
知りたいところを押すと開きます。

朝の日課 レジ 来店を数える 集計 こまったとき
🪙 朝の日課お店を開けるとき›
  1. 担当をえらぶ 開けた人の名前を押します。名前が出ないときは、設定のスタッフ名簿に入っていません。
  2. 電気をつける 押すとチェックが付きます。商品棚のスイッチも忘れずに！
  3. 音楽をかける
  4. レジ金を計算する 押すと、お札と硬貨を数える画面になります。
レジ金の数えかた
  1. 段を押す 「¥10,000」などを押すと、その段が青くなります。
  2. テンキーで枚数を打つ 打ち間違えたら ← 1字消す。その段をやり直すなら ぜんぶ消す。
  3. 「次の段へ ↓」で下の段に移る 1万 → 5千 → 2千 → 千 → 500 → … の順に進みます。0枚の段はとばして構いません。
  4. 「保存する」を押す チェックが付いて、日課の画面にもどります。
レジ金は、いつも ¥50,000 で合わせます。
数えた合計のすぐ下に、5万円とのちがいが出ます。 合わないときは、もう一度数えてから、店長に伝えてください。
画面のいちばん上に 前日の現金売上 が出ます。 昨日の現金のお会計の合計です。レジ金が合っているかを見るときの手がかりにしてください。
チェックとレジ金の記録は、1週間だけ残ります。 それより古いものは自動で消えます。この iPad の中だけの記録です。
🧾 レジお会計のしかた›
  1. 担当とお客様の区分をえらぶ 区分は 欧米／アジア／日本人。交代したら、上の「担当」から変えてください。
  2. 商品をかごに入れる 入れかたは5とおりあります（下を見てください）。
  3. 「お会計」を押す
  4. 支払い方法をえらぶ 現金のときは「預かり」を打つと、お釣りが出ます。
  5. 「会計する」を押す レシートはそのまま印刷されます。
商品の入れかた
  • 番号　値札の番号を打って「かごに入れる」。ふだんはこれ。
  • カテゴリー　種類から選ぶ。番号が読めないときに。
  • 名前　名前の一部でさがす。ひらがなでも漢字でも、入っていれば出ます。
  • 金額　商品に登録していないものを、値段だけ打って入れる。「その他 ¥450」という名前になります。
  • お持ち帰り袋・飲み物　右上のボタン。よく出るので、番号を打たずに選べます。
数を直す・消す
  • かごの中の − ＋ で数を直します。
  • 0にすると、その行は消えます。
打ち間違えてお会計してしまったら
お会計のすぐあとの画面にある 「この会計を取り消す」 を押してください。 取り消しの控えも印刷されます。
「次のお会計」に進むと、もう取り消せません。そのときは店長に伝えてください。
👥 来店を数える買わなかったお客様も数える›
  1. レジの上の「来店」を押す
  2. あてはまるところを押す 欧米／アジア／日本人 × 男／女／子供 の枠を押すと、1人ずつ増えます。
数えまちがえたら 「数を直す」 を押してから、減らしたい枠を押してください。
ここで数えたぶんが、集計の 「来場数」 に出ます。
📋 集計売上を見る›
  1. 「日別」か「月別」をえらぶ
  2. 年と月をえらぶ
  3. 「表示する」を押す
3つのタブ
  • 日別売上　日ごと・月ごとの売上とグラフ。
  • 商品別売上　どの商品が何点売れたか。
  • 来場数　何人が来たか。区分と男女・子供のうちわけも出ます。
「置き場所につないでいません」と出ているときは、 その iPad で打ったぶんだけの数字です。お店ぜんぶの売上ではありません。
🛟 こまったときよくあること›
直したはずの画面が、古いまま
  • 設定 → このアプリの版 → 「最新にする」 を押してください。
  • それでも直らないときは、アプリをいちど完全に閉じて（画面の下から上にスワイプして、カードを上に払う）、開き直してください。
  • ホーム画面のアプリと、Safari で開いたものは、別々に中身を持っています。
レシートが出てこない
  • プリンタの電源と、Wi-Fi につながっているかを見てください。
  • 設定 → レジ → レシート で、出す・出さないを切り替えられます。
スタッフの名前が出てこない
  • 設定 → スタッフ に登録すると、レジと朝の日課に出ます。
商品が見つからない
  • 「名前」のタブで、名前の一部を打ってさがしてください。
  • それでも無いときは、レジの 「金額」 のタブで、値段だけ打って会計できます。 あとで店長に伝えてください。
わからないことは、そのままにしないでください。 ご意見箱 から送れます。

お店のきまりごとも、ここに足せます。
足したいことがあれば、店長に伝えてください。
